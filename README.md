# PrepRole AI

PrepRole AI is an interview preparation platform that uses Claude AI to generate personalized technical interview questions. I built this to help IT and software professionals practice for real interviews with adaptive difficulty levels and instant feedback.

## What it does

Users enter their target job role, choose a difficulty level, and answer AI-generated multiple choice questions across 5 progressive levels. Each attempt generates completely fresh questions so users actually learn instead of memorizing answers. After completing a session, users receive a detailed performance report by email showing their scores, strong areas, and what to improve.

## Tech Stack

Frontend: React and TypeScript  
AI: Claude API by Anthropic  
Backend: AWS Lambda with Node.js  
API: AWS API Gateway  
Database: AWS DynamoDB  
Auth: AWS Cognito  
Email: AWS SES  
Workflow: AWS Step Functions  
Hosting: AWS S3 and CloudFront  
Security: AWS SSM Parameter Store, IAM, CloudTrail  
Monitoring: AWS CloudWatch
